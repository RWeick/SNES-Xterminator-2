# SNES-Xterminator-2
The Kicad files, rom dump, GAL JEDEC, and recovered AMI 18CV8PC logic for the SNES Xterminator 2 cheat device. I have redone the trace layout and added additional pads for SMD components.  
Standard jumper configuration: Pads 2, 4, 6, 8, 10, and 12 are shorted. The original firmware is available here as well as a modified one which translates it into English and is otherwise the same as the original.

Main Board PCB Thickness: 1.2 mm  
Cartridge Connector Board PCB Thickness: 1.6 mm
